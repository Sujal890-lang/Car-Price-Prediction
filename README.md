# 🚗 Car Price Prediction using Machine Learning

## 📌 Overview

This project predicts the selling price of a car based on various features such as brand, model, fuel type, transmission, mileage, engine capacity, and manufacturing year. Machine Learning algorithms are used to analyze historical car data and generate accurate price predictions.

## 🎯 Objectives

* Predict car prices using Machine Learning.
* Analyze factors affecting vehicle value.
* Improve pricing accuracy for buyers and sellers.
* Build a user-friendly prediction system.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Machine Learning Model Training
* Price Prediction
* Model Performance Evaluation

## 🤖 Machine Learning Algorithms

* Linear Regression
* Random Forest Regressor
* Decision Tree Regressor

## 📈 Results

The model predicts car prices based on user inputs and helps estimate market value with high accuracy.
